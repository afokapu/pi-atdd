## Duplicate identities, independent variables and cross-source conflicts

- **Route selection vs execution:** `PA-P-FR16` deterministic route resolution, `PA-P-FR15` projection equivalence, `PA-P-USF05` ordered execution and `PA-P-USF11` one terminal artifact are independent. A matched guard does not show the selected flow followed the authored step sequence; a correct sequence does not establish authorized delivery commit.
- **Route coverage vs negative classification:** `PA-P-FR17` demands every category assessed with typed N/A, while `PA-P-FR18` classifies each flow as route-targeted or typed single-route. Categories and route-space standing are separate axes; a default direct dispatch cannot be inferred from silence.
- **Reference vs runtime data:** `PA-P-FR12/13/14` distinguish payload declaration completeness, actual schema body presence and registry identity membership. `PA-P-FR06` forbids runtime FlowVariables inside route-control declarations; the executed FlowRunner owns that data-plane state.
- **Flow classification:** `PA-P-USF04` category (nominal/error/alternate/exception) and `PA-P-USF06` family (behavior/delivery) vary independently. A family field is a validator-checkable declaration of terminal-contract authority, not a way to grant a commit permission.
- **Source contradictions retained for adjudication:** `planner.user-system-flow.dependencies` requires numeric-prefix flow URNs where `planner.user-system-flow.naming` requires typed subject/name; `planner.user-system-flow.participants` conflicts over `product capability:` versus `capability:`; `planner.user-system-flow.theme-orchestrator-urn` describes a theme-prefixed Python runtime reference that does not straightforwardly match typed flow naming. These 3 rows remain *specifically* UNRESOLVED with source evidence, not generic unfinished rows. `planner.user-system-flow.production-implementation` (legacy Python-only runner location) is a reasoned NO_CANDIDATE from *this* engineering state extraction; it does not waive runtime implementation duties.
- **No artificial admission:** Source statements about Acceptance Authority delivery, terminal contract or named flow are **not** themselves ownership grants. D1/D2/D5 pending validator binding claims remain pending, even though each source demonstrates a potential measurable state. `PA-P-USF09` registry coherence may be measured from actual plan files independently of whether runtime can execute them.
