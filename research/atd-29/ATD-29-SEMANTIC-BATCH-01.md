## Assessment method

For each source, identify an *actual recurring state or evidence-backed state aspect*, not an action instruction or the rule itself. The **bearer** is a Resource **class**, never a particular issue, worker or file instance. Describe how the aspect can vary independently, what observed use in the authored material demands it, where its manifestation can be inspected, and what a clean negative example would look like. Candidate labels below are **temporary local labels**; similar source rules deliberately reuse one label when they describe the same state subject. No inferred relationship becomes a new `requires` edge. A validator finding is evidence of a condition, not proof of a causal Driver or policy compliance.
