## The bounded fixes made by the delivery session

1. **Documentation-format conflict:** Pinned `planner.docs.asciidoc-only` requires authored `docs/**` to be AsciiDoc (except `docs/dist/**`), with Markdown **outside** `docs/` explicitly excluded. The ATD-40 research packet originally introduced two Markdown files and one TSV under `docs/`. All three are now moved without loss to `research/atd-40/`. This avoids introducing new conflicting `docs/` paths without rewriting existing project documentation or pretending that the 21 pre-existing Markdown files under `docs/` are compliant or exempt. It is **not** a ruling about the full consumer-vs-toolkit applicability of Bun documentation rules; only a surgical mitigation for changed paths. `planner.docs.undeclared-change` and `planner.docs.artifact-path-shape` are specifically tied to an authored documentation declaration at RATIFY, which is not established in this session; no declaration is invented.
2. **TypeScript comment-context requirement:** The Bun `coder.quality.comments` rule measures 10% informative comment lines for in-scope TypeScript sources (excluding tests/vendor/build). The new `tools/atd-40-verify-ledger.ts` now explains why file blob SHA-1, catalog SHA256, source ID checks, fixture exclusions and graph witness anchors are separate, rather than padding with commentary. The actual Bun detector and its `tools/` scanning applicability must still be evaluated independently.
3. **Typecheck and runtime verification:** `tsconfig.json` now includes the **specific new tool** alongside existing source/test globs; it does not broadly include unrelated toolkit scripts. `tests/atd-40-ledger.test.ts` executes the actual checker with Node's TypeScript stripping, tests source locks and 376 YAML IDs, and checks fail-closed behavior on a missing row, changed Git digest and forged authored identity. Both run in the existing `npm run check` CI workflow, with a test header referencing real existing plan acceptance `acc:pi-atdd:E001-UNIT-002` (Bun/Flow convention fidelity) and `acc:pi-atdd:E001-UNIT-004` (invalid source must fail), **not an invented new plan URN**. Do not count those plan criteria as a separate ATD-29 Pass A completion.
