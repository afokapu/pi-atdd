# pi-atdd

Pi extension for graph-driven ATDD. Work is tracked in [Linear PLT-63](https://linear.app/forge100/issue/PLT-63/build-pi-atdd-graph-driven-pi-extension-replacing-atdd-bunflow-with).

**Status:** early implementation; existing ATDD-Bun and Flow consumers must not uninstall their toolkits yet. This repository will implement a Python-first verification adapter, on-demand convention loading, and independently reproducible required checks. The graph is versioned separately from the agent runtime.

See the first implementation task [PLT-64](https://linear.app/forge100/issue/PLT-64/pr-1-bootstrap-pi-extension-convention-graph-resolver-and-python).
