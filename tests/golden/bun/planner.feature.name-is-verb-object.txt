Title: Name every feature slug verb-object
Given: A plan contains features with URN feature:<wagon>:<name> (new, renamed or unchanged)
When: The planner names a feature slug (3rd URN segment) or the plan reaches CONFIRM
Then: Every feature slug is verb-object: kebab-case, at least two tokens, leading token a verb from the convention verb lexicon, no connective tokens.
Prefer:
- Leading verb from the feature verb-selection lexicon (conventions:planner:feature#/artifact_seeds/verb_selection)
- Slugs like make-choice, authenticate-user, route-request, preview-changes, respond-event
- List a needed brand/proper-noun slug in feature.convention.yaml verb_object_enforcement.brand_exceptions
Avoid:
- Connective slugs like respond-and-preview, route-to-mode (split or rename to one verb-object)
- Single-token slugs or a non-lexicon first token
- Implicit brand/proper-noun exceptions — unlisted is a violation
Unless:
- Slug is a brand/proper-noun listed in feature.convention.yaml verb_object_enforcement.brand_exceptions
Why: A verb-object slug names the single behaviour a feature delivers, keeping features atomic and names consistent; connectives signal bundled behaviours.
