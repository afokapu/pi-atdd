Title: Pick a feature name's verb to fit its artifact type
Given: A feature name is being authored or renamed and is seeded from an artifact whose type is event, state, data or config.
When: The planner picks the leading verb of the feature's verb-object slug.
Then: Choose a leading verb appropriate to the seeding artifact's type; the by-type verbs below are suggestions, not the only legal choices.
Prefer:
- Event: publish, emit, start, close, trigger, notify.
- State: track, monitor, maintain, update, manage.
- Data: create, manage, process, handle, make, generate.
- Config: configure, setup, initialize, define, establish.
- match:started -> start-match; session:active -> maintain-session; player:profile -> manage-profile; match:config -> configure-match.
Avoid:
- Treating the by-type table as the full set of legal verbs: alone it rejects even this convention's own examples (#1276).
- A leading verb outside verbs_by_type ∪ additional_verbs (verifier_detail[1]); the verb-object gates reject it.
Why: The artifact type (event, state, data, config) determines the appropriate verbs for the feature name, so names read consistently with what the artifact is.
