Title: Make every exposed journey reachable from the Station Master through JourneyRunner
Given: a journey document under plan/_journeys/ declares entrypoint.exposed=true and a Bun Station Master composition root (server.ts) exists
When: the repository is in that state (standing invariant; pre-existing violations count, edits are not required)
Then: every declared entrypoint action of that journey MUST be reachable from the Station Master via a JOURNEY_MAP entry { journeyId, path: "plan/_journeys/<id>.yaml" } pointing to that same journey document.
Prefer:
- Dispatch journey routes through JourneyRunner (server.ts MUST reference it): Station Master -> JourneyRunner(journeyPath) -> InterlockingRunner -> TrainRunner.
- Keep journey routes additive to action -> "train:<subject>:<slug>" and action -> { interlockingId, path }.
Avoid:
- Restating continuation edges in JOURNEY_MAP; it only establishes external reachability, the journey document is authoritative for continuation topology.
- Weakening existing direct-train or direct-interlocking mappings.
- Mapping to a journeyId/path other than the declaring document, or bypassing JourneyRunner.
Unless:
- entrypoint.exposed=false: internal journeys are intentionally not Station-Master-reachable.
- No Station Master composition root yet (PLAN stage), as for exposed interlockings.
Why: An exposed journey is executable only if the public entry reaches it via JourneyRunner; this closes the public entry direction of the journey topology.
