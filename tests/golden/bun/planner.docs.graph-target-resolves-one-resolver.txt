Title: Exactly one docs-graph resolver
Given: The docs-graph resolver.
When: You plan code that resolves doc relationship attributes.
Then: There MUST be exactly ONE docs-graph resolver. Every consumer goes through it, and no second implementation is added.
Prefer:
- Call the existing resolver instead of re-resolving `:doc-id:` targets locally.
Avoid:
- A second resolver implementation. #1755 documents seven reimplementations of lifecycle resolution.
Why: Reimplementations diverge (spec 2 §5.4, citing #1755 on the seven reimplementations of lifecycle resolution).
