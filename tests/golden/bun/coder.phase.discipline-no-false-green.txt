Title: Wire new behavior through its real owner (no false GREEN)
Given: a governed ATDD Bun task where the acceptance for newly implemented behavior passes

Why: dead-code-reachability is the one sensor that can expose a false GREEN: a unit-level acceptance can pass against code that no production root can reach.
