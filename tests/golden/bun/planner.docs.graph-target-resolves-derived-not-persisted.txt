Title: Derive the docs graph on demand and never persist it
Given: The docs graph.
When: You plan how the graph is built or stored.
Then: The graph MUST be derived from the `.adoc` attributes and rebuilt on demand. It must never be persisted.
Prefer:
- Rebuild the graph on demand from the `.adoc` attributes (spec 2 §5.3).
Avoid:
- A persisted graph. It would be a second registry, and a second registry drifts.
Why: A persisted graph would be a second registry, and a second registry drifts (spec 2 §5.3).
