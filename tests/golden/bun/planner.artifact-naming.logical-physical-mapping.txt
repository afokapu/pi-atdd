Title: Map each logical artifact name to its contract path by splitting on ':' and '.'
Given: Any work (e.g. a plan, wagon, WMBT, acceptance, doc, code or tooling) involves a logical artifact name such as scenario:fragment or sensory:gesture.raw.
When: You derive, reference or check the contract path where that artifact's schema lives.
Then: Derive the physical path by splitting the name on ':' and '.': each segment is a directory level under contracts/, the final segment the filename: <variant>.schema.json if a variant exists, else <aspect>.schema.json, or no file for a directory reference.
Prefer:
- Variant becomes the filename (gesture.raw -> gesture/raw.schema.json).
- Singular aspect -> one object schema named after the aspect.
- Plural aspect with a concrete collection -> array schema {type: array, items: $ref ../singular}.
- Plural aspect that only groups related schemas -> directory reference, no schema file.
Avoid:
- Stating a contract path that does not follow the split rule for the named artifact.
- Inventing a schema file for a directory reference, or naming the file after the aspect when a variant exists.
Why: A deterministic mapping lets anyone locate an artifact's contract from its name alone, so names and files cannot drift.
