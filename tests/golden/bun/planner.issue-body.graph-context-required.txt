Title: Populate the Graph Context section of every parent issue body
Given: You are authoring or editing the body of an ATDD parent issue
When: you write or save the issue body
Then: The body carries a Graph Context section populated with where the issue sits in the dependency graph — not missing and not left as the injection placeholder.
Prefer:
- Fill the Graph Context subsection with the issue's actual position in the dependency graph before work starts.
Avoid:
- Omitting the Graph Context section from a parent issue body.
- Leaving the Graph Context injection placeholder in place of real content.
- Filling the section with filler text just to satisfy the validator without stating graph position.
Why: A populated Graph Context section forces each issue to state where it sits in the dependency graph before work starts.
