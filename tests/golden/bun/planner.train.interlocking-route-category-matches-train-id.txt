Title: Make each interlocking route's category equal its target train's category field
Given: An interlocking and its routes.
When: You author or edit an interlocking or a targeted train's category, and whenever CONFIRM validates any interlocking (unchanged routes included).
Then: Every interlocking route declares a category (nominal/error/alternate/exception) exactly equal to the `category` field of the target train it selects.
Prefer:
- Copy the target train's `category` value into the route.
- When a train's category changes, update every route targeting it in the same change.
- If the target train lacks a `category` field, set it to the intended value first, then match the route.
Avoid:
- Deriving the category from a digit in the train identity; that legacy digit is retired and no longer parsed.
- Routes with no category or a value outside nominal/error/alternate/exception.
- Treating a target train without a `category` field as an exemption.
- Editing whichever side is easier just to silence the mismatch, without checking which reflects intended behaviour.
Why: Since issue #1421, category is a validated field on the train, not an identity digit, so a route's category must agree with the field it resolves to.
