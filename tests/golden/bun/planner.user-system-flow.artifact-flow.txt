Title: Produce every train artifact before it is consumed
Given: A train whose participant wagons pass artifacts between them
When: The planner authors or changes the train's steps, artifacts or participants, or changes artifact definitions in a participating wagon's manifest
Then: Every artifact in the train's flow must be produced before it is consumed.
Prefer:
- Name every flowing artifact as {domain}:{resource} matching ^[a-z][a-z0-9-]*:[a-z][a-z0-9.-]*$ — domain starts with a lowercase letter then lowercase letters, digits, hyphens; resource starts with a lowercase letter then lowercase letters, digits, dots, hyphens.
- Define every flowing artifact in participant wagon manifests.
- Order the flow so an artifact's producer comes before its consumers.
Avoid:
- Consuming an artifact before it has been produced.
- Referencing an artifact that is not defined in participant wagon manifests.
- Artifact names that do not match {domain}:{resource} (e.g. uppercase, no colon separator, leading digit, characters outside the allowed sets).
Why: Artifacts are what flows between train participants, so each must exist (be produced) before use and be defined where the participating wagons declare them.
