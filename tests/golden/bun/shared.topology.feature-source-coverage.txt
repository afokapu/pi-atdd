Title: Give every feature that owns WMBTs source code under its feature directory
Given: A feature in the plan owns WMBTs (behaviour to deliver).
When: The topology gate checks `<source_root>/<wagon>/features/<feature>/` for that feature.
Then: At least one source component exists beneath `<source_root>/<wagon>/features/<feature>/` for every feature that owns WMBTs.
Prefer:
- Implement the feature beneath its own feature directory.
- If another feature actually delivers the behaviour, move the WMBTs to that feature in the plan.
Avoid:
- Leaving a WMBT-owning feature with no implementation (a gap the plan already names).
- Satisfying the check with source placed only in vendored or generated trees (`node_modules`, `dist`, `build`, `_generated`); those are never scanned.
Why: A feature with behaviour to deliver and no implementation is a gap the plan already names.
