Title: Give every component URN a valid layer value
Given: A component exists or is being declared, identified by a component URN
When: The planner writes, edits or reviews that component URN
Then: The component URN contains a valid layer value, exactly one of: presentation|application|domain|integration|assembly.
Prefer:
- Put the layer in the URN's layer segment (in the source example it is the final segment), using one value spelled exactly as in the allowed set.
- For reference, each layer has typical methods / consumes / produces listed in context.repo-topology.layers (e.g. domain: process, calculate, applyRules).
- If a component spans layers, split it into one component per layer, each with its own URN carrying that single layer value.
Avoid:
- Component URNs with no layer value.
- Invented or synonym layer values (e.g. "service") outside the allowed set.
- Assigning one component to more than one architectural layer (a component belongs to exactly one layer).
Why: Pinning each component to exactly one layer keeps the layered architecture honest and lets the URN's layer segment be trusted as the single source of truth for where a component lives.
