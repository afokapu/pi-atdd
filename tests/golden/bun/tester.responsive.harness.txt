Title: Render a responsive browser spec at every declared viewport width
Given: A browser spec identified as responsive: its test URN carries the RESP code, or its file basename has a `responsive`/`resp` token.
When: You write or change that spec.
Then: Render the page at every viewport width declared in `atdd-bun.yaml` under `frontend.viewports` (default 375, 768, 1280).
Prefer:
- Iterate the declared widths and set each one: `for (const width of [375, 768, 1280]) { await page.setViewportSize({ width, height: 900 }); ... expect(scrollWidth - clientWidth).toBeLessThanOrEqual(0); }`
- Set widths via `page.setViewportSize({ width })`, a `viewport: { width }` option, or by iterating a list of widths (`for (const w of [...])`, `LIST.forEach`, `LIST.map`).
Avoid:
- Picking one element of a widths list (e.g. `WIDTHS[0]`) — that renders only one width.
- Measuring `scrollWidth` without passing it (directly or through a variable measured from it) to an `expect(...)`; the spec MUST do so, so the test fails when the page overflows horizontally (separate obligation, see split suggestion).
Why: A screen that works on a desktop can be unusable on a phone; rendering at each declared width and asserting the document never scrolls sideways is the least that proves it fits.
