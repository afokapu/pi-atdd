Title: Start likely-needed work early only when it is reversible and cannot change accepted behavior
Given: Work that may be needed later is proposed or implemented to start before its need is confirmed (any cost, any phase)
When: the planner authors or reviews that step in a plan, wagon, WMBT, acceptance or doc
Then: Allow the speculative work only if it is reversible and discarding or cancelling it cannot change accepted behavior.
Prefer:
- Consider when expensive future work is predictable and wasted work can be budgeted.
- Define isolation, cancellation and resource budgets for the speculative work.
- Test wrong predictions, cancellation races, duplicate attempts, isolation and total wasted work; measure net benefit.
Avoid:
- Speculating authority commits, irreversible side effects, externally visible mutations or unauthorized data access.
- Assuming a generic speculative journey scheduler exists or using this pattern to authorize undeclared execution.
- Inferring unimplemented orchestration behavior or a new runtime dispatch option from this pattern.
Why: Speculation saves latency only if wrong guesses are harmless; work that commits authority, mutates visibly or is irreversible cannot be cleanly discarded and would change accepted behavior.
