Title: Write each train sequence step with step, intent, from, to and one artifact
Given: A train sequence (ordered workflow steps) exists or is being written, whether you are authoring, editing, inspecting or validating it.
When: You author, edit, inspect or validate that train, including an unchanged sequence.
Then: Make sure every element of the sequence is a step that transfers exactly one artifact and declares all required fields: step, intent, from, to, artifact.
Prefer:
- Write the sequence as a flat ordered list of step elements, one artifact handoff per step (from one participant to another).
- Fill all five step fields explicitly: step, intent, from, to, artifact.
Avoid:
- Loop elements (name, condition, steps): documented but FORBIDDEN by planner.train.linearity.
- Route elements (name, branches): documented but FORBIDDEN by planner.train.linearity.
- A step missing any of step, intent, from, to, artifact, or a step transferring more than one artifact.
Why: A sequence is ordered workflow steps; each step transfers one artifact between participants, so the train stays a single linear journey whose artifact flow can be checked.
