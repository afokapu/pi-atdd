Title: Use the plane keyword cues when routing an acceptance to a test-layer plane
Given: An acceptance whose test-layer plane is being selected or reviewed
When: routing the acceptance to a test-layer plane
Then: Use the plane keyword cues in the acceptance wording when selecting its plane.
Prefer:
- Read the acceptance wording against the keyword -> plane cue table: ui: display, visible, screen, render, animation | ux: understand, clarity, steps, easy, confusing | be: validate, apply, compute, reconcile, rule | nw: request, response, timeout, websocket, stream | db: query, index, transaction, lock, row | st: asset, download, upload, cache, blob, cdn | tm: event, metrics, trace, ingest, drop | sc: schema, contract, version, field, json | au: login, token, permission, rate-limit, 403 | fn: price, balance, payout, token | if: cpu, memory, pod, node, gpu.
Avoid:
- Selecting an acceptance's plane without consulting the keyword cues in its wording.
Why: The source provides these keyword cues as the reference for selecting the test-layer plane when routing an acceptance.
