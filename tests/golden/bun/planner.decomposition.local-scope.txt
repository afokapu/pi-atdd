Title: Scope each planner run to one slice with per-invocation framing
Given: A planner invocation targets a scoped slice (plan/ may be empty or may hold artifacts from earlier runs).
When: You frame and decompose the plan for this invocation.
Then: Plan only this invocation's scoped slice, with framing derived for this invocation.
Prefer:
- Treat framing as per-invocation: different runs have different framing.
- When plan/ has existing artifacts, read them via the repo graph to compose with them.
Avoid:
- Inheriting a prior run's framing.
- Any atdd agent ask (not in this protocol).
- Any step-1 disk persistence (not in this protocol).
- Creating or using plan/_meta.yaml (not in this protocol).
- Any coach involvement (not in this protocol).
- Widening the run beyond its scoped slice.
Why: Each invocation targets a scoped slice and different runs have different framing, so framing must come from this run and the graph rather than be carried over from earlier runs.
