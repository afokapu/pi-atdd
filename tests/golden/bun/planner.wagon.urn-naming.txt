Title: Name every wagon URN wagon:{kebab-case-name}, built via URNBuilder.wagon
Given: A wagon URN is being assigned or constructed — in a plan, manifest, spec, implementation or generation code, by any author.
When: You create, rename or build the wagon's URN.
Then: Build the URN via URNBuilder.wagon so it is wagon:{kebab-case-name}, matching ^wagon:[a-z][a-z0-9-]*$.
Prefer:
- A verb-object slug that names what the wagon does (e.g. resolve-dilemmas, commit-state).
- Valid forms as in the source: wagon:resolve-dilemmas, wagon:burn-timebank, wagon:manage-users.
Avoid:
- Hand-assembling the wagon URN string instead of using URNBuilder.wagon.
- Uppercase, underscores, spaces, dots or a leading digit/hyphen in the name part.
- Omitting or misspelling the `wagon:` prefix.
- Noun-only or vague slugs when a verb-object slug fits.
Why: Feature URNs, trains and slug/dirname conversion all derive from the wagon URN, so a single predictable kebab grammar built through one builder keeps references and generated paths consistent.
