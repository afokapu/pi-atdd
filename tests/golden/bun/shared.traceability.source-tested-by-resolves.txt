Title: Resolve every implementation testing witness to an identified Bun test
Given: An implementation source declares one or more testing witnesses
When: the implementation testing witnesses are checked for resolution (at any time, regardless of which files changed)
Then: Each implementation testing witness must resolve to an identified Bun test.
Prefer:
- Point each testing witness at a concrete, identified Bun test that exists, and update the witness in the same change when that test is renamed or moved.
Avoid:
- Leaving a testing witness that names a missing, renamed or ambiguous test.
- Creating placeholder or empty tests only so a witness resolves (metric gaming).
Why: Implementation-to-test links chain with test-to-plan links into plan→test→implementation closure; a dangling witness breaks that chain.
