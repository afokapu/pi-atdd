Title: Place every source file beneath its plan-declared feature directory
Given: The plan models at least one wagon, feature or WMBT, and source files exist beneath <source_root> (the `topology.source_root` key in atdd-bun.yaml, default `src/wagons`), excluding vendored and generated trees.
When: Any source file beneath <source_root> is checked. This covers new, moved and existing unchanged files.
Then: Each such file lives beneath `<source_root>/<wagon>/features/<feature>/` for a feature the plan declares.
Prefer:
- Fix a finding by moving the file beneath its feature's directory and adding the component URN header.
- Make the URN's wagon and feature segments match the directory the file lives in.
Avoid:
- Source files under <source_root> placed outside any `<wagon>/features/<feature>/` directory.
- Placing source under a feature directory the plan does not declare.
- Leaving an in-scope source file without a well-formed `URN: component:{wagon}:{feature}:{name}:{frontend|backend}:{domain|application|integration|presentation}` header. The same validator fails on this, so treat it as required alongside placement. Its obligation is proposed as split rule atdd-bun.topology.source-urn-header.
Unless:
- Vendored and generated trees (`node_modules`, `dist`, `build`, `_generated`) are never scanned.
Why: Source is traced to its owning feature by its URN and found by its path. If either is missing, nobody can show that the feature has an implementation.
