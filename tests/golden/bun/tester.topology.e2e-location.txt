Title: Give every route and exposed journey a bound e2e proof at its canonical path
Given: The plan declares an interlocking route or exposed journey (new or existing, changed or not)
When: you change code or tests, or atdd_topology reports `atdd-bun.topology.e2e-location`
Then: Ensure it has a test at `<e2e_root>/interlockings/<interlocking>/<route>.routes.test.ts` (route) or `<e2e_root>/journeys/<journey>.journey.test.ts` (journey) carrying a `test:{wagon}:{feature}:{acceptance}` URN for a declared feature AND binding `Acceptance: acc:{wagon}:{acceptance}` declared by a WMBT; a file lacking either does not count.
Prefer:
- Add the test at exactly the path the finding names.
- Copy feature and acceptance ids from the plan's declarations.
Avoid:
- Ad-hoc e2e locations found only by searching.
- Undeclared features in URNs; Acceptance ids no WMBT declares; empty files at the path.
- An `Acceptance:` line in a browser journey spec (`tester.htmx.journey-no-acceptance-marker`).
Unless:
- Exposed journey with `frontend` surface: a Playwright `*.e2e.ts` spec substitutes when bound via `// Train:` (route's train) or `// Journey:` and carrying a valid E2E/SMOKE URN for that same subject (`test:train:<id>:E2E-NNN-…`, `test:journey:<id>:SMOKE-NNN-…`) instead of an `Acceptance:` line.
- `node_modules`, `dist`, `build`, `_generated` are never scanned.
Why: One behaviour, one end-to-end proof at a path derived from the plan: a missing proof is found by path, not by searching.
