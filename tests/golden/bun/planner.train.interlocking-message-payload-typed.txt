Title: Type every interlocking message payload
Given: An interlocking contains messages (newly authored or pre-existing)
When: The interlocking is taken to CONFIRM
Then: Every interlocking message declares either payload.contract or an explicit payload.no_payload_reason.
Prefer:
- Set payload.contract to the contract that types the data the message carries
- When the message carries no data, set payload.no_payload_reason stating why
Avoid:
- Leaving any message (including unchanged, pre-existing ones) with neither payload.contract nor payload.no_payload_reason
- Empty or placeholder no_payload_reason used only to satisfy the check while the message actually carries data
Why: Interlocking messages are integration points between participants; an untyped payload leaves the handoff ambiguous, and downstream payload checks (contract body, registry membership) presuppose a typed payload.
