Title: Make the URN name segment match the file's basename
Given: A file carries a six-segment URN and its basename is not an exempt structural role
When: the file's URN and basename are compared
Then: The URN `{Name}` segment (segment 3) MUST identify the component the file implements and match the file's basename, compared case- and separator-insensitively.
Prefer:
- During GREEN: derive the name from the actual file/component being implemented.
- During GREEN: correct a copied or stale header before considering a file rename.
- During GREEN: keep structural-role filenames as structural roles when that is their real responsibility.
Avoid:
- Copy-pasting a URN header without updating its name segment.
- Renaming a correctly named component merely to preserve a wrong URN.
- Using an exempt structural name to evade component identity.
- Changing unrelated identity segments.
Unless:
- The basename is a structural role (composition, wagon, entrypoint, http, index, schema, router, routes, server, layout, partial, fragment, middleware): the file assembles rather than implements.
- The URN is not six segments: skipped.
Why: A URN naming a different component than its file is worse than a missing one: it binds the file's evidence to somebody else's component, so both are wrong and neither is obviously wrong.
