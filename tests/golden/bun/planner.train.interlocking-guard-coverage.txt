Title: Map every executable interlocking guard path to exactly one train route or classify it as structural residual
Given: A plan containing an interlocking with executable guard paths and the train routes projected from it
When: The plan reaches CONFIRM (whether or not the interlocking was changed)
Then: Every executable guard path in the interlocking maps to exactly one train route, unless it is explicitly classified as structural residual.
Prefer:
- For each executable guard path, name the single train route that carries it, so the plan already satisfies the CONFIRM check.
- When a guard path truly belongs to no route, mark it explicitly as structural residual instead of leaving it unmapped.
Avoid:
- Leaving an executable guard path with no route and no explicit structural-residual classification.
- Mapping a guard path that is not explicitly classified as structural residual to several routes.
- Classifying routable guard paths as structural residual just to silence the coverage check.
Unless:
- The guard path is explicitly classified as structural residual.
Why: A guard path with no train route is a control path no train exercises, and one claimed by several routes has ambiguous ownership; exactly-one coverage keeps the train projection faithful to the interlocking.
