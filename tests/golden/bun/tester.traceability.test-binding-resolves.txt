Title: Make every identified Bun test name a plan item that resolves
Given: Any identified Bun test in the repository, whether or not it currently names a plan target and whether or not it was recently changed
When: the tests and the plan are checked for traceability
Then: The test must name a plan acceptance, WMBT, or train, and that named item must resolve to an existing item in the plan.
Prefer:
- Copy the exact acceptance/WMBT/train identity from the plan into the test.
- When renaming or removing a plan item, update every identified test that names it in the same change.
Avoid:
- Leaving an identified test with no named plan acceptance, WMBT, or train.
- Naming invented, stale, or misspelled plan ids.
- Adding placeholder plan items solely so a test's named target resolves (metric gaming).
- Stripping a test's identity to evade the check.
Why: A test that names nothing, or names something absent from the plan, breaks plan-to-test closure, so the plan can no longer show which behaviour each test proves.
