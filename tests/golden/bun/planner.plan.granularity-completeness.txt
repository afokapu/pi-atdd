Title: Ratify reports the dangling granularity ladder
Given: A plan session whose decomposition did not descend every rung of the granularity ladder (wagon → feature → WMBT → acceptance)
When: The plan session is ratified
Then: Ratify names the rungs of the ladder the decomposition did not descend, so the operator is told the locked plan is not testable end to end instead of having to notice it.
Prefer:
- Compose incrementally: ratify the slice in scope (planner.decomposition.local-scope) and let the report name the rungs not yet descended.
- Opt into `atdd plan ratify --strict` when the repo wants a hard gate; it unlocks before raising, so the refusal is atomic.
Avoid:
- Treating a wagons-only plan as done: it names a shape but nothing testable.
- Blocking non-strict ratification until features exist (e.g. refusing to lock eight wagons); that makes the session unusable.
Why: A wagons-only plan names a shape but nothing testable. Advisory by default, deliberately, to allow incremental composition; the failure closed is detection — only an operator holding the protocol in memory noticed a wagons-only plan had locked.
