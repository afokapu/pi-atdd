Title: Name Playwright specs *.e2e.ts
Given: A file imports `@playwright/test` and declares tests (`test(...)`, `test.describe(...)`).
When: The file is created, renamed or edited (including adding a test declaration to an existing file), or the tree is scanned.
Then: Name it `*.e2e.ts` (`.e2e.js`, `.e2e.mjs`, `.e2e.tsx` variants allowed).
Prefer:
- Rename `login.spec.ts` to `login.e2e.ts` and point Playwright's `testMatch` at `**/*.e2e.ts`.
- Keep the two runners apart: `bun test` runs unit, acceptance and smoke tests; Playwright runs only browser specs; neither picks up the other's files.
Avoid:
- Naming a Playwright spec `*.spec.*` or `*.test.*` — `bun test` collects it and runs it with the wrong runner.
- Hiding a misnamed spec from `bun test` with an ad-hoc filter instead of renaming it.
Unless:
- Vendored and generated trees (`node_modules`, `dist`, `build`, `_generated`) are never scanned.
- Files that do not import `@playwright/test` are out of scope.
- `playwright.config.*` and fixture modules that only extend `test` declare no tests and are out of scope.
Why: `bun test` collects every `*.test.*` and `*.spec.*` file, so a Playwright spec named that way runs under the wrong runner and fails, or worse is skipped by a filter nobody remembers.
