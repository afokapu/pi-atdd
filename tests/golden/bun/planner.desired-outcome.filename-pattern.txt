Title: Name WMBT files {STEP_CODE}{NNN}.yaml
Given: A WMBT file exists or is being created, renamed, moved, or reviewed.
When: You choose, change, or check its file name.
Then: Ensure the file is named {STEP_CODE}{NNN}.yaml — the step code followed by the sequence number, with no prefix.
Prefer:
- Step-coded names such as E001.yaml, L045.yaml, K023.yaml.
- When you find an existing WMBT file with a non-conforming name, rename it to the {STEP_CODE}{NNN}.yaml form.
Avoid:
- Any prefix before the step code (e.g. a 'wmbt-' or wagon-name prefix) — the name must be step-coded with no prefix.
Why: The filename is the WMBT URN's step-coded sequence segment, so a predictable {STEP_CODE}{NNN}.yaml name keeps file and URN aligned.
