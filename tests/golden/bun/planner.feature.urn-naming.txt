Title: Name feature URNs feature:{wagon}:{verb-object}, built via URNBuilder.feature
Given: A feature URN is being constructed, declared, renamed or referenced in any artifact or code
When: The feature URN value is written or changed
Then: The feature URN must be built via URNBuilder.feature and have the form feature:{wagon}:{feature}, both segments kebab-case (matching ^feature:[a-z][a-z0-9-]*:[a-z][a-z0-9-]*$), with the feature segment in {verb}-{object} form.
Prefer:
- Use the parent wagon's slug verbatim as the {wagon} segment.
- Shape the feature segment as verb-object, e.g. feature:resolve-dilemmas:choose-option, feature:manage-inventory:track-stock, feature:manage-users:authenticate-user.
Avoid:
- Hand-concatenating feature URN strings instead of using URNBuilder.feature.
- Uppercase, underscores, camelCase or segments starting with a digit or hyphen.
- Noun-only or object-verb feature names (e.g. stock-tracking instead of track-stock).
- Omitting the wagon segment or adding extra colon-separated segments.
Why: The feature URN is the feature identifier, so it must have one fixed, checkable form.
