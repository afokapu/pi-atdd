Title: Prefix each WMBT sequence with one of the nine step codes
Given: A WMBT sequence prefix (in its URN and filename) is being selected, changed, or evaluated.
When: The planner chooses or checks the single-letter step code that prefixes the WMBT sequence.
Then: Use exactly one code from D L P C E M Y R K, the one whose step intent matches the WMBT: D define (requirements, criteria, constraints), L locate (discover/find resources), P prepare (setup/configure prerequisites), C confirm (verify/validate conditions), E execute (perform/run the main action), M monitor (observe/track progress), Y modify (update/adjust state), R resolve (fix/handle issues), K conclude (complete/finalize).
Prefer:
- Pick the letter by the step's intent from the code table, not by the first letter of the verb (modify is Y, conclude is K).
- Use the same code consistently in the WMBT URN and its filename.
Avoid:
- Inventing letters or multi-letter codes outside the nine-code vocabulary.
- Choosing a code by spelling (e.g. M for modify, C for conclude) instead of by the defined mapping.
- Defaulting every WMBT to E to avoid deciding the step's intent.
Why: WMBT URNs and filenames embed the step code, so a closed, shared letter→intent vocabulary keeps WMBT identifiers parseable and the step's purpose readable from its id.
