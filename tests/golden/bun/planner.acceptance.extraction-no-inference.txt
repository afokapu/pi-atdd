Title: Ask the user for missing acceptance context; never infer or suggest it
Given: You are extracting an acceptance and some context (e.g. which wagon it belongs to) is missing from what the user has stated.
When: You need to obtain or fill in that missing context.
Then: Obtain the missing context by asking the user directly — do not infer it and do not offer suggestions.
Prefer:
- Pure conversational extraction: ask the user directly about the gap, e.g. the wagon_inference prompt 'Which wagon should this acceptance belong to?'
- Wait for the user's answer before writing the context into the acceptance.
Avoid:
- Guessing (inferring) missing acceptance context from surrounding material and writing it in.
- Offering suggestions or pre-filled candidate answers instead of asking directly.
Why: No inference is the policy of asking rather than guessing missing acceptance context; direct extraction supplies the context the abstract acceptance fields require and keeps the acceptance complete and faithful to the user's intent.
