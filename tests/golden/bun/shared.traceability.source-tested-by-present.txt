Title: Declare a testing witness for every implementation component
Given: An implementation component identified by the traceability closure check
When: The component is created or changed, or the closure check runs
Then: The component declares a testing witness.
Prefer:
- Declare the testing witness in the same change that introduces the component, naming the test that exercises it
Avoid:
- Leaving an identified implementation component with no declared testing witness
- Declaring a placeholder or unrelated witness just to satisfy the presence check
Why: Traceability closure requires every implementation component to point to the test that witnesses it; a witness can only be resolved and checked once it is declared.
