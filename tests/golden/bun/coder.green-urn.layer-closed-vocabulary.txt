Title: URN layer segment must be one of the five core layers
Given: A file declares a six-segment URN; segment 5 is the layer the boundary and dependency-flow rules read to judge imports.
When: You write or change the URN, or the detector reports its layer as invalid.
Then: Set segment 5 to exactly one of `domain`, `application`, `integration`, `presentation`, `assembly`.
Avoid:
- Inventing a new layer. Core fixes the vocabulary, not this extension; a new layer is a core change.
Unless:
- The URN is not six segments; it is skipped.
Why: Layering rules read segment 5 to decide whether an import is legal. A layer outside the vocabulary is not just mislabelled: no layering rule can reach the file, so it becomes a hole that lets any dependency pass unchallenged.
