Title: Scaffold criteria from the chosen harness's catalog template
Given: You need a given/when/then scaffold, or the typical layers, for a criterion using one of the 13 catalog harnesses (http, unit, event, ws, e2e, a11y, visual, metric, job, db, sec, load, script) — drafting before any file exists, revising, or just looking it up.
When: You draft, generate, revise, or look up that criterion's scaffold or layers.
Then: Start from the catalog entry harness -> {layers, given/when/then scaffold} (verbatim, listed in prefer), replacing its placeholder values with the criterion's real ones.
Prefer:
- http — layers [presentation, application, domain, integration]; given {auth: {scopes: [purchase:create]}}; when {method: POST, path: /api/example, headers: {Content-Type: application/json}, body: {sample: true}}; then [{kind: status, expect: 200}, {kind: body, expect: {ok: true}}].
- unit — layers [application, domain]; when {target: Service.method, args: {payload: {sample: true}}}; then [{kind: result, expect: {ok: true}}].
- event — layers [application, integration]; when {topic: sample.event, payload: {sample: true}}; then [{kind: event, expect: sample.event}] (expect names the same topic).
- ws — layers [integration]; when {url: ws://example/events, subscribe_msg: {action: subscribe, channel: updates}}; then [{kind: message, expect: {frame: connected}}].
- e2e — layers [presentation, application, domain, integration]; when {url: http://example/ui, actions: ['fill #field', 'click #submit']}; then [{kind: visual, expect: success-banner}].
- a11y — layers [presentation]; when {}; then [{kind: a11y, expect: passes}].
- visual — layers [presentation]; when {}; then [{kind: snapshot, expect: unchanged}].
- metric — layers [application, integration]; when {}; then [{kind: metric, expect: metric:placeholder}].
- job — layers [application, integration]; when {}; then [{kind: status, expect: completed}].
- db — layers [integration, domain]; when {}; then [{kind: rows, expect: updated}].
- sec — layers [application, integration]; when {}; then [{kind: security, expect: granted}].
- load — layers [integration, application]; when {}; then [{kind: metrics, expect: within_limits}].
- script — layers [application]; when {}; then [{kind: status, expect: 0}].
- Treat each template's layers as the layers the harness typically exercises — a default, not a mandatory declaration.
Avoid:
- Leaving template placeholder values (/api/example, sample: true, Service.method, example URLs, metric:placeholder) in a finished criterion.
- Inventing an ad-hoc given/when/then shape for a harness that already has a catalog template.
Why: A reusable scaffold per harness keeps criteria uniform and records which layers each harness typically exercises.
