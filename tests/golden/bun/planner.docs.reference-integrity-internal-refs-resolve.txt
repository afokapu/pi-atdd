Title: Every internal cross-reference in the docs corpus resolves
Given: The documentation corpus is being validated, whatever changed.
When: The docs validator checks the corpus's xref: and <<anchor>> cross-references between corpus documents.
Then: Every internal cross-reference MUST resolve. An unresolvable internal reference is FAIL.
Prefer:
- Fix a reported reference by fixing its target or the reference itself
Avoid:
- Leaving an xref: or <<anchor>> that points at a document or anchor that does not exist
Unless:
- External links are not resolved. Their liveness is a network property, and checking it would make the gate non-deterministic.
Why: Unresolvable internal references must be VALIDATION FAILURES. That is why asciidoctor, not a Python renderer, is the reference implementation.
