Title: Write every per-case @covers tag as a full acc:{wagon}:{ACCEPTANCE-ID} URN
Given: A Bun test case (it()/test()) has a `// @covers` comment block directly above it, binding that ONE case (not the file) to acceptances
When: the tester writes, edits, or encounters (existing, unchanged) any such tag
Then: Every tag in the block MUST be a full URN `acc:{wagon}:{ACCEPTANCE-ID}` (e.g. `// @covers acc:orders:E005-UNIT-001`), never a bare ID like `// @covers E005-UNIT-001`.
Prefer:
- Before tagging: identify the acceptance this exact case exercises, confirm its stimulus reaches that behavior, and that a behavioral assertion witnesses the declared outcome.
- Several URNs on one line only when one case genuinely proves several acceptances.
- Per-case tags plus the file header (two-level binding): many cases to one acceptance without one acceptance per file.
Avoid:
- Bare/partial IDs missing the `acc:` scheme or wagon.
- Valid URNs added for coverage credit when the case does not exercise and assert them; fiction the detector cannot catch.
Unless:
- The case has no `@covers` tag: none is required; the file header binding still applies.
Why: A malformed tag is strict because it binds nothing while looking exactly like a working binding; tags are semantic claims too, so precision needs them well-formed and true.
