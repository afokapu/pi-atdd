Title: Give every produced wagon artifact grammar-conformant contract and telemetry URNs
Given: A wagon produces, or is being planned to produce, one or more artifacts, in whatever file or document they are defined.
When: The planner defines, modifies or reviews any wagon-produced artifact or its contract/telemetry URN.
Then: Give each produced artifact a contract URN of the form contract:{theme}(:{category})*:{aspect}(.{variant})? and a telemetry URN of the form telemetry:{theme}(:{category})*:{aspect}(.{variant})?, following the artifact-naming grammar.
Prefer:
- Write both URNs for every produced artifact, using the same theme/category/aspect path segments so the contract and telemetry identities line up.
- Use ':' to separate theme, zero or more categories, and aspect; use a single '.' only before an optional variant on the last segment.
Avoid:
- Producing an artifact with only a contract URN or only a telemetry URN.
- URNs without the 'contract:' / 'telemetry:' scheme prefix, with no theme or aspect, or with '.' used as a category separator.
- Inventing ad-hoc naming shapes that the artifact-naming file mapping cannot resolve.
Why: Contract URNs map to contract files and telemetry URNs map to the telemetry filesystem through the artifact-naming grammar; a URN outside that grammar breaks resolution for producers and consumers across wagon boundaries.
