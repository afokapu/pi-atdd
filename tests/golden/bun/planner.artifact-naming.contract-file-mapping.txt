Title: Map each artifact name to its contract file path with the fixed formula
Given: An artifact name (theme, optional segments, final segment, e.g. theme:seg1:seg2:aspect.variant or theme:aspect.variant) is mapped to a contract file path, in any document, code or tooling.
When: You write, reference or compute the contract file path for that artifact.
Then: Derive the path deterministically: contracts/ + theme and each segment as directories, the final segment as the filename, with the .schema.json extension (theme:seg1:seg2:aspect.variant -> contracts/theme/seg1/seg2/aspect/variant.schema.json).
Prefer:
- Split the artifact name on ':' and '.' and turn every part except the last into a directory under contracts/; the last part becomes <part>.schema.json.
Avoid:
- Hand-picked or flattened paths that do not mirror every name segment (e.g. collapsing segments into one filename).
- Keeping ':' or '.' from the artifact name in the file path, or using an extension other than .schema.json.
- Renaming an artifact without moving the referenced contract path to match.
Why: The artifact-name -> file-path transform is deterministic, so any tool or reader can locate a contract from its name alone; a path that diverges breaks that lookup.
