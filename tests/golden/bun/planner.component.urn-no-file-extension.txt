Title: No file extensions in component URNs; use a lang-* facet
Given: A component URN is involved, in any artifact
When: choosing or checking its {name} segment, especially when you want to show a language
Then: Never put a file extension (.py, .dart, .ts, .tsx, etc.) in a component URN. If a language must be expressed, use a 'lang-*' facet.
Avoid:
- component:resolve-dilemmas:choose-option:OptionValidator.py:backend:domain (file extension).
Why: The URN names a logical component, not a file.
