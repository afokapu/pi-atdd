Title: Component URNs are case-sensitive: store and reuse them exactly as written
Given: A component URN is stored or referenced
When: you record or reuse it
Then: Treat component URNs as case-sensitive: store and reuse each one exactly as written.
Avoid:
- Re-casing or case-normalising an existing component URN.
Why: The graph addresses components case-sensitively, so a re-cased URN points to a different component or to none.
