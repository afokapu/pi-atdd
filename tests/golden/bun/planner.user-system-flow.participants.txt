Title: Declare each train participant once as wagon:, user: or system: id
Given: A train workflow definition whose actors (wagons, human roles, external systems/data sources) are declared as participants
When: The planner authors, edits or checks that train's participant declarations
Then: List each participant exactly once as `wagon:{wagon-id}`, `user:{role}` or `system:{source}`, matching `^(wagon|user|system):[a-z][a-z0-9-]*$`.
Prefer:
- Use `wagon:` for a wagon that performs processing, `user:` for a human actor's role, `system:` for an external system or data source
- Make the id part start with a lowercase ASCII letter, followed by zero or more lowercase ASCII letters, digits or hyphens
Avoid:
- Listing the same participant more than once
- Using any type prefix other than wagon, user or system, or omitting the prefix
- Uppercase letters, underscores, spaces or a leading digit or hyphen in the id part
- Typing a human actor or an external source as a wagon (or the reverse)
Why: Train steps move artifacts between declared participants, so a uniquely named, typed actor list keeps every step's source and destination unambiguous and checkable.
