Title: Declare a device-width viewport in every full HTML document
Given: Any full HTML document in scope: an `.html`/`.htm` file, a `.tsx`/`.jsx` layout rendering `<html>`, or a `.ts`/`.js` template building one
When: the document exists in the repository (new or existing)
Then: The document declares `<meta name="viewport">` whose content sets `width=device-width`.
Prefer:
- Declare `<meta name="viewport" content="width=device-width, initial-scale=1">` in each full document and keep zoom available.
- During GREEN: add or correct the single viewport declaration in the document/layout that serves the current behavior.
- During GREEN: reuse the existing shared layout when one owns the document head.
Avoid:
- Duplicating viewport tags across fragments.
- Blocking zoom (MUST NOT): `user-scalable=no` or a `maximum-scale` below 2.
- Restructuring unrelated head markup.
Unless:
- Fragments that are not full documents (no `<html>`) are out of scope.
- Viewport `content` given as a JSX expression (`content={VIEWPORT}`): the meta must be present; its value is not judged.
Why: Without a device-width viewport a phone renders a zoomed-out desktop layout, whatever the CSS says. Blocking zoom fails users who need to enlarge text, also an accessibility failure.
