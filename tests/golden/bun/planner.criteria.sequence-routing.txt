Title: Use the layer-to-default-action map for route sequences
Given: A route sequence has steps assigned to the presentation, application, domain or integration layer
When: You define, select or check the default action for a layer in that sequence
Then: Use the layer's default action: presentation → command, application → use_case, domain → validate, integration → persist.
Prefer:
- Write steps as <layer>.<default action>: presentation.command, application.use_case, domain.validate, integration.persist.
Avoid:
- Giving a layer a different default action than the map, for example making persist the domain default or validate the presentation default.
Why: With one fixed layer-to-default-action map, every route sequence uses the same defaults, so sequences stay consistent and predictable.
