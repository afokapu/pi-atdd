Title: Give each implemented train its own train:{theme}:{train_id} URN line on the theme orchestrator
Given: A theme orchestrator file python/trains/orchestrators/{theme}.py exists or is planned, and it implements one or more trains.
When: Any planning artifact or doc you author creates, changes (including internal-logic edits) or describes that orchestrator, or you find it missing URN lines.
Then: Ensure the orchestrator file carries one `# urn: train:{theme}:{train_id}` line per implemented train, with {theme} matching the file's theme.
Prefer:
- When one orchestrator implements several trains, plan multiple `# urn:` lines, one for each train.
- When an existing orchestrator lacks a URN line for a train it implements, plan the missing line as part of the work.
Avoid:
- A single combined or unprefixed URN line covering several trains.
- URNs whose theme segment differs from the orchestrator's {theme} filename.
- URN lines for trains the orchestrator does not actually implement, added only to satisfy a check.
Why: The theme-prefixed orchestrator URN is what ties each implemented train to its theme orchestrator file, so every implemented train must be traceable by its own URN line.
