Title: Component URN = component:{wagon}:{feature}:{name}:{side}:{layer}
Given: A component URN is involved, in any artifact
When: you write, build, reference or store it
Then: It must be component:{wagon}:{feature}:{name}:{side}:{layer}, exactly six parts separated by ':', and must match the canonical lint regex.
Prefer:
- {wagon} = parent wagon id; {feature} = parent feature id; {name} = logical component name; {side} = frontend|backend|fe|be (deployment side); {layer} = presentation|application|domain|integration|assembly (architectural layer).
- Train infrastructure: wagon 'trains', layer always assembly, e.g. component:trains:runner:TrainRunner:backend:assembly.
- Wagon entrypoints: feature 'wagon'.
- Example of a feature composition component (above layers): component:navigate-domains:browse-hierarchy:composition:backend:assembly.
Avoid:
- Separators other than ':' between segments, or missing or extra segments.
Why: A stable, colon-separated URN ties each component to its owning wagon and feature and fixes its deployment side and architectural layer, so the graph can address components unambiguously.
