Title: Name each WMBT with a unique step-coded URN wmbt:{wagon}:{STEP_CODE}{NNN}
Given: Any artifact (plan, wagon, acceptance, doc or code), by any author, contains a WMBT (what-must-be-true) URN.
When: A WMBT URN is created, modified or referenced.
Then: The URN is a unique identifier of the form wmbt:{wagon}:{STEP_CODE}{NNN}, built via URNBuilder.wmbt(wagon_id, sequence), where wagon is the parent wagon id in kebab-case, STEP_CODE is a single step letter, and NNN is a three-digit zero-padded sequence 001-999.
Prefer:
- Generate the URN with URNBuilder.wmbt(wagon_id, sequence) rather than hand-typing it.
- Use the parent wagon's own kebab-case id as the {wagon} segment.
- Pick the step letter from the step-code vocabulary (D, L, P, C, E, M, Y, R, K) and a three-digit zero-padded sequence in 001-999 that keeps the URN unique.
Avoid:
- Reusing a URN already assigned to another WMBT (URNs must be unique).
- Unpadded or out-of-range sequences (e.g. 1, 45, 000, 1000) or multi-letter / lowercase step codes.
- Using a wagon segment that is not the parent wagon or is not kebab-case (uppercase, underscores, leading digit).
Why: The WMBT URN is the WMBT's stable identity: it embeds the owning wagon and step code so filenames, acceptances and traceability tooling can resolve it unambiguously.
